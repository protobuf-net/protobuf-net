# Working notes

Internal notes and generated snapshots. **Not published**, and that is the whole point of the
directory: `docs/` is the source for <https://docs.protobuf-net.dev>, so anything placed there is
built into the site *and* listed in `sitemap.xml` by the `jekyll-sitemap` plugin. There is no
`exclude:` in `docs/_config.yml`, so "it is obviously internal" buys nothing — the test is which
directory it is in.

Four AOT files lived under `docs/` for exactly that reason and were moved here: two are working notes
(`aot-findings.md`, `aot-grpc.md`) and two are tool output (`aot-coverage.md`, `aot-differential.md`,
regenerated by `src/AotCoverage` and `src/AotDifferential`).

The split to keep:

- **`docs/`** — written for someone using protobuf-net. `docs/aot.md` is the AOT page that belongs there.
- **`notes/`** — written for whoever picks the work up next: handovers, what was probed and what it
  showed, what was decided and why, and snapshots that are regenerated rather than maintained.
