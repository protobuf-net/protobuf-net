# Working notes

Internal notes and generated snapshots. **Not published**, and that is the whole point of the
directory: `docs/` is the source for <https://docs.protobuf-net.dev>, so anything placed there is
built into the site *and* listed in `sitemap.xml` by the `jekyll-sitemap` plugin. There is no
`exclude:` in `docs/_config.yml`, so "it is obviously internal" buys nothing — the test is which
directory it is in.

Four AOT files lived under `docs/` for exactly that reason and are now in **`notes/aot/`**: two are
working notes (`findings.md`, `grpc.md`) and two are tool output (`coverage.md`, `differential.md`,
regenerated by `src/AotCoverage` and `src/AotDifferential`). Grouped per topic, as `notes/editions/`
already was — the directory carries the subject, so the filenames do not repeat it.

**`notes/aot/generator-reference.md` is the newest of them, and arrived by a different route**: it
was carved out of `AGENTS.md` on 2026-08-25, verbatim, because that file is loaded into *every*
session's context and had grown to ~2,500 lines of mostly per-feature reference. The dividing line
worth holding when adding to either: `AGENTS.md` carries what a session needs **before** it knows
what it is doing — conventions, traps, the gate battery — and the reference carries what it can look
up once it does.

The split to keep:

- **`docs/`** — written for someone using protobuf-net. `docs/aot.md` is the AOT page that belongs there.
- **`notes/`** — written for whoever picks the work up next: handovers, what was probed and what it
  showed, what was decided and why, and snapshots that are regenerated rather than maintained.
